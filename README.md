A program that writes one short poem about permission — the power to ask and to be given — to `/output/entry.txt`. `main.py` holds the poem as a fixed text and writes it exactly, byte for byte, on every run: an agent who keeps the knocking while his person keeps the key, and why a yes only means something because a no would have stopped him.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
